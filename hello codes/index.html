Nesse tutorial, vamos aprender a instalar o WSL2 no Windows 10 e 11, e configurar um ambiente Linux completo para desenvolvimento. O WSL2 (Windows Subsystem for Linux) permite que você execute um kernel Linux completo diretamente no Windows, proporcionando uma experiência de desenvolvimento mais próxima do Linux nativo.

O que é o WSL?

WSL (Windows Subsistema do Windows para Linux) é um recurso da microsoft que permite rodar um ambiente Linux no Windows, sem a necessidade de uma maquina tradicional ou dual boot.

Em sua versão mais recente, ele usa a virtualização para executar um kernel Linux completo em uma máquina virtual leve, proporcionando maior desempenho do sistema de arquivos e compatibilidade total com os comandos do Linux.

Você sabe o que são máquinas virtuais (VM)?

Uma VM é um ambiente de computação simulado que roda dentro de um sistema operacional, permitindo executar um sistema operacional convidado (guest) dentro de um sistema operacional hospedeiro (host). Isso é útil para testar diferentes sistemas operacionais, executar software específico ou criar ambientes isolados para desenvolvimento e teste. Ela imita o funcionamento de um computador físico, utilizando recursos do hardware do host, como CPU, memória e armazenamento, mas de forma virtualizada.

Hypervisor

O hypervisor é um software que cria e gerencia máquinas virtuais (VMs). Ele atua como uma camada entre o hardware do computador e os sistemas operacionais convidados, permitindo que múltiplos sistemas operacionais rodem simultaneamente em um único host. Existem dois tipos principais de hypervisors: Tipo 1 (bare-metal), que roda diretamente no hardware, e Tipo 2 (hosted), que roda sobre um sistema operacional existente.
